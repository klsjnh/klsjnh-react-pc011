# 016.api-contract.md — 接口通讯规则

## 统一响应信封（六字段固定）

{
  "statusCode": 200,
  "message": "select success",
  "errorMessage": "",
  "timestamp": 1788645689571,
  "traceId": "b7c1e2f0a3d94e8f",
  "data": null
}

## URL 结构

/api/v1/{模块}/{动作}

## 标准动作

| 动作 | 方法 | 说明 |
|------|------|------|
| selectOne | POST | 查询单个 |
| selectListByPage | POST | 分页查询 |
| insert | POST | 创建 |
| update | POST | 更新 |
| logicDelete | POST | 逻辑删除 |

## 错误码

| statusCode | message | 场景 |
|:---:|---|---|
| 200 | <action> success | 成功 |
| 400 | bad request | 入参失败 |
| 401 | unauthorized | 未认证 |
| 403 | forbidden | 无权限 |
| 500 | internal server error | 服务端异常 |
