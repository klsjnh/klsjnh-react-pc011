# 013.project-info.md — 项目信息（pc-admin 前端）

> **定位**：项目背景、前后端模块对应关系、技术栈与骨架。
> 目录与骨架细则见根目录 [`README.md`](../README.md) §目录结构；文档体系见 [`011.agreements.md`](011.agreements.md)。

## 011.背景

- **pc-admin** 是「PC 前端 + Java 17 DDD 后端」体系中的 **PC 端前端**仓库
- 当前阶段：前端功能完整、数据以内置 Mock 提供；已具备 **Mock / API 双数据模式**，按 [`016.api-contract.md`](016.api-contract.md) 契约可直接对接后端
- 后端框架仓库：`klsjnh-java17-framework011`（Java 17 纯血 DDD 技术底座：Spring Boot 3.4.5 · MyBatis-Plus 3.5.9 · MySQL 8）

## 013.技术栈

| 项 | 选型 |
|---|---|
| 框架 | React 18.3（函数组件 + Hooks） |
| 语言 | TypeScript 5.6 |
| 构建 | Vite 6 |
| 路由 | 无路由库，hash 路由（`App.tsx` pageMap 分发） |
| 状态管理 | 无第三方库，`useSyncExternalStore` 自研 store（localStorage 持久化按需） |
| UI | 无 UI 组件库，自研全局 CSS 约定（`src/styles/global.css`） |

## 015.前后端模块对应关系

前端页面模块命名 `julyXxx`（全单词），与后端 `requirement011/` 业务设计**同编号贯穿**：

| 后端主题（requirement011） | 前端页面 | 路由 |
|------|------|------|
| `018.topic-july-menu.md`（菜单） | `src/pages/system011/julyMenu.tsx` | `#/menu` |
| `019.topic-july-user.md`（用户） | `src/pages/system011/julyUser.tsx` | `#/user` |
| `022.topic-july-role.md`（角色含权限挂菜单） | `src/pages/system011/julyPermission.tsx` | `#/permission` |
| （组织机构主题待后端立项） | `src/pages/system011/julyOrganization.tsx` | `#/organization` |

## 016.骨架

```
src/
├── api/        # 请求封装（POST + 统一信封，对齐 016 契约）
├── config/     # 运行时配置（数据模式 mock/api）
├── stores/     # useSyncExternalStore 自研状态（auth/menu/role/notification/ui）
├── components/ # 通用组件（弹窗/穿梭框/布局）
├── pages/      # 页面（system011/ 为系统管理模块）
├── mock/       # 内置 mock 数据
└── styles/     # 全局样式与 PC 组件类约定
```

细则见 [`../README.md`](../README.md)。
