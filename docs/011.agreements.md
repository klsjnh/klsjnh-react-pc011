## 013.编号规则（全局序列）

编号（`{编号}`）是**全仓库共享的一支序列**，与所在目录**无绑定关系** —— 同一个号可以作目录名、主题文件名，也可以作文档内小节号。

- **分配规则（两条禁忌）**：从 `011` 起**递增分配**，**跳过含数字 `4` 的号**（`014 / 024 / 034 / 040–049 / 140–149 …`），并**跳过 `012`**；其余**连号不留空**
- **序列取值**：`011 / 013 / 015 / 016 / 017 / 018 / 019 / 020 / 021 / 022 / 023 / 025 / …`
  - `013.project-info` / `015.coding-standards` / `016.api-contract` 属顶层常驻文档，占用全局号
- **不复用、不回收**：一个号一经分配即永久占用 —— 文件改名、移出、归档、撤销均**不释放**该号
- **文档内小节号（分层独立起编）**：**每一级各自**从 `011` 起，按**同一规则**递增（跳 `012` 与含 `4` 的号）；**同级内递增**，不跨级连续
  - 父级与其首个子节**可以同号**（层级不同，不算冲突）
  - 跨节引用**连父级一起写**（如 `§011 · 013`），仅写 `§011` 会与父节歧义
- **同一主题同编号贯穿**：`{编号}.topic-{主题}.md`（主题 kebab-case 英文）在各阶段目录**同名**
- **编号 ≠ 层级（铁律）**：小节号不代表层级，层级**只由内容决定**
