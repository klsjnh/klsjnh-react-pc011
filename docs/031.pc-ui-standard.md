# 031 — PC 端 UI 标准（蓝本：用户管理 · 权限管理）

> **蓝本即标准**：新页面 / 改造旧页，先对蓝本再动工。
> **单表金标准 = 用户管理**（`pages/system011/julyUser/index.tsx`，2026-09-21 用户定稿配色）；**主子表左右分栏蓝本 = 权限管理**（`pages/system011/julyPermission/index.tsx`）；**主子表上下结构蓝本 = AI 模型供应商**（`pages/aiCenter/JulyAiModelProvider/index.tsx`）与**字典管理**（`pages/system011/julyDictionary/index.tsx`）；树表参照组织管理；**树主子表蓝本 = 菜单管理**（`pages/system011/julyMenu/index.tsx`）。
> **性质**：项目相关（React 19 + Ant Design 6 + SCSS 设计令牌）。表单布局铁律归 [016.coding-standards §9.1](016.coding-standards.md) —— 本文只链接、不复制正文（E2）。
> **来源**：2026-09-21 依用户指示以蓝本体系重写；按钮风格条款（§016）经同日全局对齐落地。

## 011.形态判定（先定型，再抄蓝本）

**六型业务页**：

| # | 页面形态 | 判定 | 蓝本 |
|---|----------|------|------|
| 1 | **单表** | 一个资源、平铺行、搜索+筛选+勾选批量 | 用户管理 `julyUser` |
| 2 | **主子表 · 左右分栏** | 主项是**轻量列表**（名称+状态），选中后右侧配置/明细（树 / 小表 / 表单） | 权限管理 `julyPermission` |
| 3 | **主子表 · 上下结构** | 主子都是**数据表**、各自要完整工具栏与列信息 | AI 模型供应商 `JulyAiModelProvider`（同型：字典管理 `julyDictionary`、存储管理 `julyStorage`） |
| 4 | **树表** | 数据本身是树、无分页 | 组织管理 `julyOrganization` |
| 5 | **树主子表** | 左树即主项（选中节点），右侧编辑区为子区 | 菜单管理 `julyMenu` |
| 6 | **整页编辑器** | 单实体大表单 / 设计器，脱离列表页 | 提示词明细编辑器 `PromptDetailEditorPage`（同型：低代码设计器 `MetadataFormPage`、建模页 `ModelingFormPage`、文件编辑器 `FileEditorPage`） |

**选型指引**（2 vs 3）：主表行需要展示多列数据、子表也要自己的工具栏 → 上下结构；主项是轻量清单、子区是配置视图（勾选树 / 穿梭框 / 单小表）→ 左右分栏。

**辅助形态**（非 CRUD 骨架，不套 §013 列表骨架，但 §016 按钮 / §018 弹窗条款仍适用）：

| 形态 | 页面 | 要点 |
|------|------|------|
| **Tab 聚合页** | 消息中心 `messageCenter/index` | 一路由多资源 `Tabs`（+ `Segmented`）切换；每个 Pane = 无页头单表（自带搜索 + 按钮区） |
| **仪表盘 / 统计页** | 仪表盘 `DashboardPage`、报表 `ReportsPage` | 指标卡 + 图表，无表格工具栏 |
| **特殊页** | 登录 `login`、AI 聊天 `JulyAiChat`、运行时动态页 `SchemaRuntimePage`、通知 / 个人中心、占位页 | 独立设计；改造需用户确认 |

- **新页面先归入六型之一**，再抄对应蓝本；归不进的（落入辅助形态或新形态）须先与用户确认再建。

## 013.页面骨架

**单表**（照抄 julyUser 的纵向 flex）：

```tsx
<div className="page-fill">
  <div className="page-header"><h2>用户管理</h2></div>
  <div className="page-toolbar" style={{ display: 'block' }}>
    <div className="toolbar-row-search" ...>{/* 第一行：搜索 + 筛选 */}</div>
    <div className="toolbar-right">{/* 第二行：动作按钮 */}</div>
  </div>
  <Card className="table-wrapper" ref={cardRef} styles={{ body: { padding: 0 } }}>
    <Table ... />
  </Card>
</div>
```

**主子表 · 左右分栏**（照抄 julyPermission）：

```tsx
<div className="page-header"><h2>权限管理</h2></div>
<div className="permission-layout">
  <Card className="permission-sider" title="角色" extra={...新建+编辑...}
        styles={{ body: { padding: 8, minHeight: 670, overflowY: 'auto' } }}>
    <List ... />  {/* 主项列表，点击选中 */}
  </Card>
  <div className="permission-main">
    {!selected ? <Card className="permission-empty"><Empty description="引导文案" /></Card>
               : <Card title={selected.name}><Tabs items={...} /></Card>}
  </div>
</div>
```

**主子表 · 上下结构**（照抄 JulyAiModelProvider）：

```tsx
<div className="page-fill">
  <div className="page-header"><h2>AI 模型供应商</h2></div>
  <div className="page-toolbar">...</div>  {/* 只服务主表 */}
  <Card className="table-wrapper">{/* 主表 Table，行点击选中 .master-row-selected */}</Card>
  <Card title={`API 密钥 · ${selected?.name ?? ''}`} extra={...子表工具栏...}>
    {selected ? <Table ... /> : <Empty description="未选中提示" />}
  </Card>
</div>
```

- 两张 `table-wrapper` Card 垂直排列、flex 均分高度，**各自** `useTableFillHeight` 实测 `scroll.y`。
- 子表 Card 标题带主项名；未选中主项 → 子表区给 `Empty` 引导，**不许白板**。

- **页头**：默认 `h2` 一行；需要统计 / 说明时才加 `p` 副标题（如定时任务的「共 N 个任务」）。不放大按钮。
- **高度**：左右分栏两栏 `minHeight: 670`，右主区再加 `maxHeight: 670, overflowY: 'auto'`；单表 / 上下主子表高度交给 `useTableFillHeight` 实测。

## 015.搜索区（工具栏第一行 · 左侧）

以 julyUser 为准：

| 项 | 规格 |
|----|------|
| 搜索框 | `Input.Search` + `allowClear`，**宽 260**，placeholder「搜索××」语义化（搜索账号 / 搜索编码 / 名称） |
| 行为 | `onSearch(v) => fetchXxx({ pageIndex: 1, 字段: v || undefined })` —— **搜索必回第一页**；关键词受控（`value` + `onChange`） |
| 下拉筛选 | `Select` **宽 140**，首项「全部×」`value: ''`；变更即生效（本地过滤或重新请求） |
| 数量上限 | 搜索框 1 + 筛选 ≤2；再多的筛选项收进下拉或抽屉，**不许堆满一行** |
| 位置 | 第一行靠左（`toolbar-row-search` 或 `toolbar-left`）；右侧不放按钮 |
| 例外 | 上下主子表的工具栏只服务主表；子表搜索 / 刷新放子表 Card `extra` 或子表工具条 |

## 016.按钮（个数 / 状态 / 位置）

**单表 / 上下主子表的主表工具栏**（`toolbar-right` 右对齐，从左到右固定排序）：

| # | 按钮 | 写法 | 状态规则 |
|---|------|------|----------|
| 1 | 新建（不带资源后缀） | `color="green" variant="filled"` + `PlusOutlined` | 恒可用 |
| 2 | 批量删除 | `color="danger" variant="filled"` + `DeleteOutlined`，套 `Popconfirm` | 无选中 `disabled`；删除中 `loading`；**仅当表格带 rowSelection 时才出现** |
| 3+ | 次要动作（备份 / 导出 / 刷新…） | 备份类 `color="blue" variant="filled"`；导出 `color="pink" variant="filled"`；其余 default + 语义图标 | 异步中 `loading`（按动作区分，如 `actionLoading === 'export'`）；导出多格式用 `Dropdown` + `DownOutlined` |

- **总数 ≤4**：新建 1 + 批量 1 + 次要 ≤2；超出的动作收进 Dropdown。
- **工具栏禁实心 primary**（`type="primary"` 只允许出现在保存场景，见下）。

**主子表 · 左右分栏按钮位置**（照抄 julyPermission）：

| 位置 | 按钮 | 状态规则 |
|------|------|----------|
| 左 Card `extra` | 新建主项（tonal primary）+ 编辑（`type="link"`） | 编辑：未选中主项 `disabled` |
| 右主区每 Tab 顶部（`text-right mb-2`） | **保存 = 唯一实心**（`type="primary" size="small" loading={saving}`）；次要动作（添加用户 = tonal primary small + `PlusOutlined`）放保存**左侧** | 保存按钮全局共用一个 `saving` 态 |
| 子表行内 | 移除（`type="link" size="small" danger`） | 草稿行直接删，不打后端 |

**主子表 · 上下结构按钮位置**（照抄 JulyAiModelProvider）：

| 位置 | 按钮 | 状态规则 |
|------|------|----------|
| 主表工具栏 | 单表同款（新建 / 批量删除 / 次要） | 同单表 |
| 子表 Card `extra` | 新增子项（tonal primary small + `PlusOutlined`）+ 刷新（default tonal small） | 未选中主项时新增 `disabled` |
| 子表行内 | 测试 / 编辑 / 删除（filled small：编辑 primary、删除 danger + Popconfirm；存量 link 页面遇改渐次收敛） | 需已保存实体的动作（如测试连接）新建态禁用 |
| 字典管理变体 | 类型卡 extra「新建字典类型」、项卡 extra「新建字典项」（均 tonal small） | 未选类型时「新建字典项」`disabled` |

**树表 / 树主子表**：

- 树表（组织管理）：工具栏右侧「新建集团」（tonal primary + 图标）；行内「编辑 / 子部门 / 删除」为 filled small（编辑 primary、删除 danger + Popconfirm；存量 link 遇改渐次收敛）。行内新增子级**不带 + 前缀**。
- 树主子表（菜单管理）：左树即主项 —— 新建根入口在左 sider `extra`（tonal primary small）；右侧编辑区保存钮在右 Card `extra`（实心 primary）；树节点增删走右键菜单、层级调整走拖拽，不设行内按钮列。

**整页编辑器**：页头动作区 **返回列表 + 保存居左、无取消**（返回即放弃），保存实心 primary —— 详见 [016 §9.1](016.coding-standards.md)。

**统一状态语义**：`disabled` = 前置条件未满足；`loading` = 异步进行中且防重复提交；不可逆动作必套 `Popconfirm`（`okText="删除"` / `cancelText="取消"` / `okButtonProps={{ danger: true }}`）。

**统一文案**：单表金标准的新建文案为「新建」（不带资源后缀）；存量「新建×」页面可保留，遇改统一到「新建」。其余：`编辑` / `删除` / `批量删除` / `保存` / `取消` / `刷新`；禁「+」文字前缀、禁「新增」（存量「新增一行 / 新增 API」为子表行级保留字，不扩散）、弹窗 footer 确认钮一律「保存」不写「确定」。

**五色语义（2026-09-21 用户定稿）**：新建 = `green`、备份类 = `blue`、导出 = `pink`、危险 = `danger`、主确认 = 实心 `primary` —— 各司其职，页面不得引入语义外的散点色；行内操作用 filled 小按钮（编辑 primary / 删除 danger），不再用 link。其他页面未对齐处，遇改渐次收敛到本口径。

## 017.表格（按形态）

**单表 / 上下主子表主表**（julyUser 口径）：

- **勾选**：`rowSelection` 仅当存在批量操作；`rowKey="id"`。
- **列**：显式 `width`；内容左对齐 + 表头居中（`hdrCenter` / `leftCell` 工具写法）；空值渲染 `—`。
- **状态列**：`width: 90` + `align: 'center'`，`Tag`（启用/正常 `green`，停用 `red` 或 `default`）—— 禁裸文本 0/1。
- **操作列**：`fixed: 'right'`，宽按动作数 90–200。
- **滚动**：`scroll={{ x: 列宽合计, y: tableBodyHeight }}`，y 由 `useTableFillHeight(cardRef, signature)` 实测。
- **分页**：`current/pageSize` 取自 store query；`showSizeChanger` + `PAGE_SIZE_OPTIONS`（pageSizePref 持久化）+ `showTotal: 共 N 条`。

**主子表 · 左右分栏**（julyPermission 口径）：

- 左 sider 用 `List`（非 Table）：`role-item` + `active` 选中高亮；项结构 = 图标 avatar + `title` 名称 + `description` 编码 + 右侧状态 `Tag`。
- 右主区未选中给 `Empty` 引导卡（「请从左侧选择××」），**不许白板**。
- `Tabs` 的 label 带实时计数：`` label: `菜单权限 (${n})` ``。
- **草稿 + 保存**：右侧编辑先改本地草稿，点保存才落后端；切换主项重置草稿（渲染期以 id 为键调整 state，不进 useEffect，规避级联渲染）。
- 子表 `Table size="small" pagination={false}`。

**主子表 · 上下结构**（JulyAiModelProvider 口径）：

- 主表行点击选中（`.master-row-selected` 高亮）；**选中态按 id 从最新列表派生**（编辑后子表标题自动跟新、删除后自动清选中）。
- 子表列与主表同规格（Tag / 空值 / 操作列）；分页按子表量级 —— 数据少 `pagination={false}`，量大同单表分页口径。

**树表**（julyOrganization 口径）：

- 树形 `Table`：`dataSource` 直接喂树、`expandable={{ defaultExpandAllRows: true }}`、**`pagination={false}`**。
- 层级可视：一级节点加粗 / `Tag` 展示编码；操作列含「子部门」新增入口。

**树主子表**（julyMenu 口径）：

- 左侧 `Tree`：拖拽调层级 + 右键菜单（新建子菜单 / 删除），树 Card `extra` 放「新建顶级菜单」；不套 `Table`、无操作列。
- 右侧编辑表单与选中节点联动；保存钮在右 Card `extra`（实心 primary），编辑态不可变字段（编码）`disabled`。

## 018.弹窗与表单（按钮摆放）

- 弹窗 footer：`[取消] [保存]`，保存 = 实心 primary + `confirmLoading`；`destroyOnHidden` + `key={id ?? 'new'}` 重挂载让 initialValues 定型（antd 6 字段注册时序 —— 不用 setFieldsValue effect）。
- 编辑态不可变字段（编码）用 `disabled`，不条件渲染隐藏。
- 字段布局铁律（短字段独占一行 / 长文本整行 KlsjnhMarkdown011 / 整页编辑器页头 返回+保存居左）→ [016 §9.1](016.coding-standards.md)。

## 019.执法与审计

- 本标准全部为 **【评审】** 类规则（017 §D1）：任务执行时 AI 对照蓝本逐项自查；不进正则门禁。
- 快速审计命令：

```bash
# 工具栏实心 primary（应无输出；仅保存场景允许）
grep -rnE '<Button[^>]*type="primary"' src/pages --include=*.tsx
# 装饰前缀（应无输出）
grep -rn '>\+ ' src/pages --include=*.tsx
# 存量「新增」按钮（只允许子表行级）
grep -rn '>新增' src/pages --include=*.tsx
```
