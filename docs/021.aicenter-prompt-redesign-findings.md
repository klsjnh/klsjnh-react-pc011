## 021.2 端点清单（16:59 实测，17 个）

```text
域主表（树）   GET  getByCode / getById / selectTree / getWithChildren   POST selectListByPage / insert / update / logicDelete
提示词明细     GET  getDetailById / getContent / getDetailByCode         POST selectDetailListByPage / insertDetail / updateDetail / logicDeleteDetail
整存+渲染     POST saveWhole（域+prompts 整存替换） / render（promptCode+params）
```

要点：**明细端点与前端前端先行时约定的动作集同名对上**（selectDetailListByPage / insertDetail / updateDetail / logicDeleteDetail）；`getWithChildren` / `saveWhole` 是新增的打包形态。

## 021.3 数据模型（schema 逐字段）

### 域主表 `JulyAiDomainVo011`（与 16:39 SAME）
`id` / `domainCode`（全局唯一不可变）/ `domainName` / **`parentId`（树，根空串）**/ `sortOrder` / `status` / `remark` / `children[]`。

### 提示词明细 `JulyAiDomainPromptSaveVo011`（insert/update 通用形态）
| 字段 | 说明 |
|------|------|
| `promptCode` | 编码，全局唯一**创建后不可修改**（required） |
| `promptName` | 名称 ≤100（required） |
| `scene` | inference / image / tts（仅分类） |
| `contentMode` | inline 入库 / storage 落对象存储 |
| `content` | 正文（inline 直接入库；storage 时作为落存储的内容） |
| `storageCode` / `bucket` | storage 模式（缺省默认实例 / **缺省桶 ai-prompt**） |
| `variables` | 变量声明可空 |
| `sortOrder` / `remark`(≤300) / `status` | 留空默认启用 |

Query（selectDetailListByPage 入参 `JulyAiDomainPromptQueryVo011`）：`keyword` / `pkMt` / `scene` / `status` + 分页。

### 打包 `JulyAiDomainBundleVo011`：`domain` + `prompts[]`（getWithChildren 出参）
### 整存 `JulyAiDomainSaveWholeVo011`：域字段 + `prompts[]`，**整存替换语义（旧子表逻辑删 + 新列表插入）**；域 id 留空=新增。
