# 011 — Single-Table Development Standard (Blueprint: julyConfig / 配置管理)

> **本手册是什么**：以「配置管理」为蓝本，给出**单表页面**从零到验收的完整开发流水线 —— 拿到一个新单表需求，照本手册逐节执行即可。
> **蓝本文件**（3 文件拆分，2026-09-21 定稿）：`pages/system011/julyConfig/` 下的 `index.tsx`（页面壳）/ `ConfigTable.tsx`（表格）/ `ConfigFormModal.tsx`（弹窗）。

> **语言**：目录 / 文件名 / 标题英文（检索与链接友好）；内容中文（团队阅读习惯）。

## 011.Before You Start（动手前核查单）

1. **契约先行**：从线上拉取实时 OpenAPI（`GET {backend}/v3/api-docs`），确认资源路径、动作集、每个 VO 的字段与 required —— 字段名**逐字对齐**，不猜（§C1/C3）。
2. **形态判定**：确认页面确属**单表**（一个资源、平铺行、可勾选批量）；主子表 / 树表 / 树主子表走 031 §011 对应蓝本。
3. **能力盘点**：核对后端有无 export / backup011 / logicDeleteBatch —— **按钮跟着端点走**，后端没有的能力不放假按钮。
4. **缺字段走「前端先行」**：后端 VO 暂缺某字段（如 status / remark）而用户已拍板要 UI 时，前端类型标 `?` + 注明「前端先行 + 日期」、service 照常透传、mock 支持 —— 后端补齐后零改动生效。

## 013.File Layout（3 文件拆分）

```text
src/pages/system011/julyConfig/
├── index.tsx          # 页面壳：页头 + 工具栏（搜索/筛选 + 动作按钮）+ 组装；弹窗与勾选状态持有者
├── ConfigTable.tsx    # 表格：store 取数 / 列定义 / 勾选 / 分页 / 实测高度；行内动作回调上抛
└── ConfigFormModal.tsx# 弹窗：表单 + 提交（saveXxx 内部已刷新列表，壳不重复刷）
```

**职责边界**：

| 文件 | 持有 | 禁止 |
|------|------|------|
| `index.tsx`（壳） | 弹窗 open/node、勾选 keys、批量删除 loading、动作按钮 loading | 写列定义、写表单字段、直接调 api |
| `*Table.tsx` | 无（全部从 store 读；动作经 props 回调上抛） | 持有弹窗状态、写业务提交逻辑 |
| `*FormModal.tsx` | 表单实例、saving | 重复刷列表（service 已刷）、持有其他组件状态 |

**store / service / types** 按既有分层落位（见 016 §16 新增业务功能动线），函数名逐字对齐端点动词。

## 015.Page Shell（壳的固定结构）

```tsx
<div className="page-fill">
  <div className="page-header"><h2>配置管理</h2></div>
  <div className="page-toolbar" style={{ display: 'block' }}>
    <div className="toolbar-row-search" ...>{/* 第一行：Input.Search + Select 筛选 */}</div>
    <div className="toolbar-right">{/* 第二行：新建 + 批量删除 + 次要动作 */}</div>
  </div>
  <ConfigTable ... />       {/* 表格组件 */}
  <ConfigFormModal ... />   {/* 弹窗组件 */}
</div>
```

- **第一行**：`Input.Search`（宽 260，受控 keyword，`onSearch` 回第一页）+ 状态 `Select`（宽 140，`全部状态/启用/停用`，值取 `query.status ?? ''`，变更即查）。
- **第二行按钮**（金标准五色语义，031 §016）：新建 `green`「新建」/ 批量删除 `danger`（无选中禁用）/ 备份类 `blue` / 导出 `pink`（多格式 `Dropdown`）。**没有对应端点的按钮不加**。
- 批量删除必须 `Popconfirm`（`okText="删除"` `cancelText="取消"` `okButtonProps={{ danger: true }}`）。
- 壳在 `useEffect` 里只拉一次首页数据：`fetchXxxPage({ pageIndex: 1 })` —— pageSize 是用户偏好，不回写。

## 016.Table（表格组件规格）

- 从 store 读 `list/total/loading/query`；`rowKey="id"`；`rowSelection` 仅当壳有批量操作（keys 由壳持有，`onChange` 上抛）。
- 列：显式 `width`；编码类 `render: (v) => <code>{v}</code>`；空值 `—`；枚举状态 `Tag`（green/red）；`hdrCenter`/`leftCell` 工具写法（内容左对齐、表头居中）。
- **列序（2026-09-21 定稿）**：…… → 备注 → 状态 → 操作（备注在状态前，全站统一）。
- `scroll={{ x: 列宽合计, y: tableBodyHeight }}`；`y` 由 `useTableFillHeight(cardRef, `${total}-${loading}`)` 实测。
- 分页：`current/pageSize` 从 store；`showSizeChanger` + `PAGE_SIZE_OPTIONS` + `showTotal: 共 N 条`。
- 行内操作：filled 小按钮 —— 编辑 `color="primary" variant="filled" size="small"`、删除 `color="danger" variant="filled" size="small" danger` + `Popconfirm`；经 `onEdit(row)` / `onRemove(id)` 回调上抛给壳。

## 017.Form Modal（弹窗规格）

- Modal：`key={node?.id ?? 'new'}` + `destroyOnHidden` + `confirmLoading`；footer `取消/保存`（保存 = 实心 primary）。initialValues 直接由 `node` 派生，**不用 setFieldsValue effect**（antd 6 字段注册时序）。
- **字段布局（2026-09-21 定稿，全站铁律）**：
  1. 编码 / 名称等短字段**各占一行**（禁 Row/Col 并排挤放）；编码编辑态 `disabled`。
  2. **备注永远排在状态前面**；两者**各自独占一行**。
  3. **备注一律多行**：`Input.TextArea rows={2}`（长备注 3 行）；后端限长时加 `maxLength` + `showCount` + `extra` 说明。
  4. 状态 `Select`（STATUS_OPTIONS / 资源专用 options），required 必填。
- 提交：`form.validateFields()` → `saveXxx({...})`（service 内部已刷列表）→ toast → `onClose()`；异常 toast 不吞。

## 018.Data Layer（数据层五件套）

| 层 | 落点 | 要点 |
|----|------|------|
| types | `types/system011/{module}/vo.ts` | 契约类型逐字对齐 OpenAPI；前端先行字段标 `?` + 注释；`view.ts` 放 store 状态与 SaveParams |
| service | `services/system011/{module}Service.ts` | 函数名对齐端点动词；泛型返回；`saveXxx` 内部区分 insert/update 并刷新列表；删除按契约 —— 单删 `IdVo011`、批量 `logicDeleteBatch` + `IdsVo011`（**禁裸数组**） |
| store | `stores/system011/{module}Store.ts` | zustand 工厂；分页偏好走 `pageSizePref` |
| mock | `mock/system011/{module}.ts` | 按 action 路径分发；支持 keyword/status 过滤；insert/update 落前端先行字段；删除 handler 与契约同构 |
| 路由/菜单 | `config/routes.ts` + `config/constants.ts` | 一条路由一处注册；菜单 path 用路由常量，不写裸字符串 |

## 019.Checklist（提交前自查）

1. 契约字段名与快照逐字一致？前端先行字段有注释？
2. 3 文件拆分到位？壳没写列定义、表格没持弹窗态？
3. 工具栏按钮与端点一一对应（无假按钮）？五色语义正确？
4. 搜索回第一页？状态筛选值取自 `query.status`？
5. 列序备注在状态前？弹窗字段序一致、备注 TextArea 多行？
6. 行内 filled 小按钮 + Popconfirm？
7. 分页偏好走 pageSizePref？实测高度喂 scroll.y？
8. mock 支持全部前端先行字段与筛选？
9. `./script011.sh gate` 全绿（tsc → eslint → 规范自检）？
