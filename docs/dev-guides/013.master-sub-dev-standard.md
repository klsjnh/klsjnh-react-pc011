## 011.Before You Start（动手前核查单）

1. **契约先行**：拉实时 OpenAPI（`GET {backend}/v3/api-docs`），确认主子两个资源的路径、动作集、VO 字段与 required —— 字段名**逐字对齐**；子表是否有独立的 insertItem/updateItem/logicDeleteItem 三件套决定子表交互形态。
2. **形态判定**：主表是数据表且子表需要完整操作区 → **上下结构主子表**（本手册）；主项是轻量清单（名称+状态）→ 左右分栏（031 §011 蓝本 = 权限管理）。
3. **能力盘点**：主表有无 export / backup011 / logicDeleteBatch —— 按钮跟端点走；字典无批量删除端点 → 工具栏不放批量按钮。
4. **缺字段走「前端先行」**：后端 VO 暂缺字段时，类型标 `?` + 注明「前端先行 + 日期」、service 照常透传、mock 支持、UI 呈现；后端补齐后**删注释转正即可，调用方零改动**（字典 status/remark 即此路径）。

## 013.File Layout（4 文件拆分）

```text
src/pages/system011/julyDictionary/
├── index.tsx              # 页面壳：页头 + 工具栏 + 组装；弹窗 open/node 持有者
├── DictionaryTable.tsx    # 主表列表：Card + 列定义 + 行选中 + 分页（固定10）+ 实测高度
├── DictionaryFormModal.tsx# 主表编辑弹窗
└── DictionaryItemTable.tsx# 子表列表：行编辑草稿模型（新增行/行内编辑/删除标记/批量保存）

**职责边界**：

| 文件 | 持有 | 禁止 |
|------|------|------|
| 壳 `index.tsx` | 弹窗 open/node、搜索关键字、导出 loading | 写列定义、写子表草稿逻辑 |
| 主表 `*Table.tsx` | cardRef / 实测高度（useTableFillHeight） | 持弹窗态；行内编辑经 `onEdit(row)` 回调上抛 |
| 主表弹窗 `*FormModal.tsx` | form / saving | 重复刷列表（service 已刷） |
| 子表 `*ItemTable.tsx` | 草稿 rows / rowsSaving / 选中行编辑态 | 直接调 api（走 service）；未保存数据静默丢弃 |

  <div className="page-toolbar">
    <div className="toolbar-left">
      <Input.Search ... />   {/* 宽 260，受控 keyword，onSearch 回第一页 */}

      <Button color="green" variant="filled" icon={<PlusOutlined />} ...>新建</Button>

  <Card className="table-wrapper" style={{ marginTop: 16 }}>
    <Tabs className="detail-tabs" items={[{ key: 'items', label: '明细项', children: <ItemTable active={active} /> }]} />
  </Card>
  <DictionaryFormModal open={...} node={...} onClose={...} />

```

- **工具栏（2026-09-21 定稿）**：**单行、全部靠左** —— 搜索 → 状态筛选 → 按钮紧随其后（`toolbar-left` 一个容器紧排；⚠️ `.page-toolbar` 自带 `space-between`，控件直铺会被拉满整行，必须包进 toolbar-left）。
- **按钮五色语义**（031 §016）：新建 `green`「新建」（不带资源后缀）/ 导出 `pink` / 备份类 `blue` / 批量删除 `danger`（仅当有批量端点且表格带勾选）；无端点不放假按钮。
- **危险动作**必套 `Popconfirm`（`okText="删除"` / `cancelText="取消"` / `okButtonProps={{ danger: true }}`）。

## 016.Master Table（主表规格）

- 包 `<Card className="table-wrapper" title="字典" styles={{ body: { padding: 0 } }} ref={cardRef}>`；`useTableFillHeight(cardRef, \`${total}-${loading}\`)` 实测 → `scroll={{ x: 列宽合计, y: tableBodyHeight }}`。
- **行点击选中**：`rowClassName` 挂 `.master-row-selected` + `onRow onClick → selectDictionary(row)`（写 store.active）；子表订阅 store 自动联动。选中态派生自最新列表（编辑/删除后自动跟随）。
- **分页（主子表定稿）**：`pageSize: 10` 固定、`showSizeChanger: false`、`onChange: (pageIndex) => fetchXxx({ pageIndex, pageSize: 10 })` —— 不用 pageSizePref。
- **对齐（2026-09-21 定稿）**：单元格与表头**一律左对齐** —— 不写 `hdrCenter` / `onHeaderCell` / `align: 'center'`；编码列 `<code>`；空值 `—`；状态 `Tag`（green/red）。
- 列序：业务列 → **备注 → 状态** → 操作。
- 行内操作：filled 小按钮（编辑 `color="primary" variant="filled" size="small"`、删除 `color="danger" ... danger` + Popconfirm）；行内新增子级文案不带「+」前缀。

## 017.Sub Table（子表 · 行编辑草稿模型）

蓝本 = `DictionaryItemTable`，核心机制：

- **草稿态**：服务端 items 拉回后映射为草稿行（`_key` / `_editing` / `_dirty` / `_deleted` / `_isNew`）；effect 依赖**必须是 store 里引用稳定的 `items`**（映射放 effect 内）—— 依赖每次渲染重建的数组会 setState 死循环（已踩坑）。
- **单行编辑**：同一时刻最多一行处于编辑态；进入某行编辑时其余行退出但**改动保留**。
- **删除 = 标记**：`_deleted` 标记 + 底色样式（`.draft-row-deleted`），未保存前可「撤销删除」；新行删除直接移出草稿。
- **保存 = 一次性提交**：先删（腾出编码）后增改；项编码唯一性校验（含与未改动行比对）；成功后 `fetchXxxItems(...)` 刷新 store → 草稿自动重置。
- **操作条**：子表上方 `.detail-actions` —— 新增一行（tonal primary small + `PlusOutlined`，未选中主项 disabled）+ 保存（tonal primary small + `SaveOutlined`，无脏行 disabled）+ 脏行计数提示。
- 子表 `pagination={false}`；列序同为 备注 → 状态 → 操作；备注列行内可编辑。

## 018.Form Modal（主表编辑弹窗）

- `key={node?.id ?? 'new'}` + `destroyOnHidden` + `confirmLoading`；initialValues 由 `node` 派生，**不用 setFieldsValue effect**。
- **字段布局（全站铁律 016 §9.1）**：编码（编辑态 disabled）/ 名称 / 排序**各占一行**；**备注 TextArea 多行在前**（`rows={2}`，限长加 maxLength+showCount+extra）；**状态在后**、required 必填。
- 提交走 `saveXxx({...})`（service 内部区分 insert/update 并刷新列表与选中）→ toast → `onClose()`。

## 019.Data Layer（数据层要点）

| 项 | 规则 |
|----|------|
| types | 主子两套 VO 按域分文件；前端先行字段标 `?` + 日期注释；转正时删注释 |
| service | `saveXxx` / `saveXxxItem` 内部区分 insert/update 并透传全字段（status/remark）；单删 `IdVo011`、批量 `logicDeleteBatch` + `IdsVo011`，**禁裸数组** |
| store | `active`（选中主项）+ `items/itemsLoading`（子表数据）与列表态同存；分页偏好（主子表主表）固定 10，不入 pageSizePref |
| mock | 主子全动作覆盖；insert/update 落 status/remark；分页支持 keyword/status 过滤 |
| 路由/菜单 | 一条路由一处注册；菜单 path 用路由常量（julyDictionary 收敛案例：演示页双路由已清除） |
