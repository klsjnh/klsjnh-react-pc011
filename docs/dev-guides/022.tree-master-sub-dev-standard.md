## 011.Before You Start（动手前核查单）

1. **契约先行**：拉实时 OpenAPI，确认「主资源树端点（selectTree）」与「明细端点集（insertDetail/updateDetail/logicDeleteDetail/selectDetailListByPage/getDetailById）」是否存在 —— **明细端点决定子表交互形态**：有 → 按域直查（本手册）；无 → 先推动后端补齐，前端不聚合凑合。
2. **形态判定**：主项有层级（parentId 挂树）+ 明细挂主项 → **树主子表**（本手册）；主项平铺 + 子表要完整工具栏 → 上下结构（013）；主项轻量清单 → 左右分栏（031 §011）。
3. ** Vo 是否回传大字段**：正文/大内容字段若不在 Vo 里（蓝本即如此：`JulyAiDomainPromptVo011` 无 content），走 `getContent` 点查回填 —— **列表不背正文**。
4. **URL 语义**：`?domain=<域id>`（蓝本语义为**域 id**，不是编码）；路由注册一处，菜单 path 用路由常量。

**职责边界**：

| 文件 | 持有 | 禁止 |
|------|------|------|
| 壳 `index.tsx` | 选中域（URL `?domain=`）、弹窗 open/node、导航 | 写树/表内部逻辑；直接调 service（走面板上抛） |
| 左树 `DomainPanel.tsx` | 树数据渲染 + 右键菜单 | 持明细列表态；直接操作 store 写树（经 service） |

| 弹窗 `*FormModal.tsx` | form / saving | 手写 footer div（Modal okText 内建）；重复刷列表 |
| 编辑器 `*EditorPage.tsx` | 正文草稿 / getContent 回填 | 弹窗化（正文超长必须整页）；丢改守卫缺失 |

## 015.Page Shell（树壳固定结构）

```tsx
<div className="page-fill">
  <div className="page-header"><h2>AI 提示词</h2></div>
  <div className="prompt-layout">   {/* 左右分栏：左树 300px 自适应卡，右栏 flex:1 */}
    <Card className="prompt-sider" title="业务域" styles={{ body: { padding: 8 } }}
      extra={<Button size="small" color="primary" variant="filled" icon={<PlusOutlined />}
        onClick={() => setDomainModal({ open: true, node: null, parentId: '' })}>新建顶级域</Button>}>
      <DomainPanel onSelect={(id) => patchQuery({ domain: id })} />
    </Card>
    <PromptPanel />   {/* 订阅 query.pkMt，选中域变化自动直查 */}
  </div>
  <DomainFormModal open={...} node={...} parentId={...} domainTree={tree} onClose={...} />
  <PromptFormModal open={...} node={...} pkMt={activeDomain} onClose={...} />
</div>
```

- **左树头部按钮**：Card `extra` 新建顶级域（tonal primary **small** + `PlusOutlined`）—— 树根入口属 031 §016 分栏口径，**不是**工具栏 green。
- **选中域是唯一数据开关**：URL `?domain=` 为真源，壳解析后写 store.query.pkMt；右表 effect 订阅 `query.pkMt` 自动 `fetchPromptsByDomain(pkMt)`，未选域渲染空态引导。
- **树/表联动零手写**：不写「点树 → 手动 setList」的胶水，数据流 = 树 onSelect 改 query → 明细面板 effect 自查。

## 016.Tree Panel（左树规格 · KlsjnhTreeList011）

树一律用 `components/klsjnh011/KlsjnhTreeList011` 原语组装，**不裸写 antd Tree**：

- **必配 props**：`nodes`（store.tree）/ `getKey` / `renderTitle`（节点文案 + 计数徽标）/ `selectedKey` + `onSelect`（受控选中）/ `loading` / `emptyText`。
- **右键菜单**：`nodeActions` + `onAction` 注入 —— 新建子域 / 编辑 / 删除（删除必套 Popconfirm 语义，蓝本在 onAction 内 confirm）。菜单动作**上抛壳处理**，面板不持弹窗态。
- **拖拽**（如需层级调整）：`draggable` 与 `onDrop` **必须成对出现** —— 只挂 draggable 不挂 onDrop 是悬空残废（021 迁移期踩过，检查器口径）。
- **树数据**：`selectTree` 返回成品树（parentId/children），前端不自行拼装；`fetchDomainTree()` 写 store，写操作后统一重拉。

## 017.Sub Table（右栏明细 · 按域直查）

- **分页**：管理端规模可固定上限（蓝本 `pageSize: 200` 一次拉，`totalPages: 1`），**不走 pageSizePref**；数据量大时改标准分页（pageIndex 变更重查）。
- **列规格**：对齐 031 §017 —— 显式 width、左对齐、空值 `—`；状态列 `KlsjnhStatusTag011`；行内 filled small（编辑 primary / 删除 danger + Popconfirm）。
- **行内跳转**：「设置」跳正文编辑器（路由跳转带 `promptId`），不在弹窗里编辑长文本。
- **未选域空态**：`Empty` 引导「先选择左侧业务域」，禁全量拉取。
- **新增入口**：工具栏「新建」按钮（green filled，**主表工具栏口径**）+ 未选域 disabled；行内不做新增。

## 018.Form Modal（树节点/明细编辑弹窗）

- **结构（金标准 2026-09-22 重构后形态）**：`XxxFormBody` 内嵌 `<Modal>`（Modal 与 Form 同组件，`onOk={handleSave}` / `okText="保存"` / `cancelText="取消"` / `confirmLoading={saving}`）；外层壳 `open ? <Body key={...}/> : null` 条件渲染。
- **key 重挂载**：`key={node?.id ?? \`new-${parentId}\`}` —— 每次打开全新 form 实例 + initialValues 定型，**不用 setFieldsValue effect**（回填时序坑）。
- **字段布局（016 §9.1 铁律）**：编码（编辑态 disabled）/ 名称 / 上级（树场景）/ 排序；**备注 TextArea `rows={2}` 在前**（maxLength+showCount 按需）；状态在后必填。
- **树特有**：上级域/上级菜单 Select 数据来自树展平（层级缩进），**编辑态排除自己及子树防环**（`containsId` 递归，蓝本 DomainFormModal 即样板）。
- 提交走 `saveXxx`（service 内 insert/update 分流并重拉树）→ toast → `onClose()`。

## 019.Data Layer（数据层要点）

| 项 | 规则 |
|----|------|
| types | 树节点 VO（children: 自引用数组）与明细 VO 分文件；明细 Vo **不含大字段**（蓝本 content 不回传）；Insert/Update Vo 精确分离 |
| service（主） | `selectTree` 拉成品树 + insert/update/logicDelete（update 可改 parentId = 移动挂载点）；saveXxx 内部分流并 `fetchDomainTree()` 重拉 |
| service（明细） | `selectDetailListByPage({ pkMt })` 按域直查 + getDetailById 点查 + getContent 大字段点查 + insertDetail/updateDetail/logicDeleteDetail；render 独立动作端点 |
| store（主） | 极简 `{ tree, loading }` —— 树无分页；分页/筛选机制不放树上 |
| store（明细） | `{ list, total, totalPages, loading, query }`；**query.pkMt 必须回写**（savePrompt/removePrompt 事后按同域刷新依赖它，勿删） |
| mock | 主子全动作覆盖：树 CRUD + saveWhole + 明细五端点 + CONTENT_REPO 正文仓；防环校验同步 mock |
| URL/路由 | `?domain=` 域 id；编辑器路由带 `promptId`；路由常量注册一处 |
